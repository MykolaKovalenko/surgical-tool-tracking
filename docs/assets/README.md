# Demo assets

Place the short public demonstration here before publishing the repository.

Recommended asset:

- `tracking-demo.gif` or `tracking-demo.mp4`;
- 15-30 seconds;
- visible class labels, confidence, and persistent track IDs;
- at least one occlusion, crossing, or failure case;
- no patient-identifying information and only media that may be redistributed.

Link the asset from the top of the root README once it has been generated.
